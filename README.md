# Machine Learning (Neural Network)

Learning machine learning from the ground up through Python, neural networks, automatic differentiation, and language models.

This repository contains my code, experiments, and Jupyter notebooks as I work through the fundamentals of how neural networks learn.

## What I'm Learning

- **Neural Networks** — Neurons, layers, weights, biases, and activation functions.
- **Automatic Differentiation** — Computational graphs, gradients, and backpropagation.
- **Optimization** — Understanding how gradients are used to update model parameters.
- **Language Models** — Character-level language modeling and learning patterns from text.

## Getting Started

### Requirements

- Python
- Jupyter Notebook or Visual Studio Code
- The dependencies listed in `pyproject.toml`

### Setup

Clone the repository:

```bash
git clone https://github.com/Davidputra6000CC/Learning.git
cd Learning
```

Install the project dependencies using [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Open the notebooks in VS Code or Jupyter and execute the cells to explore the experiments.
